My System 0.1.0 preview for Windows 11 x64.

Native WinUI monitoring, real Windows telemetry providers, opt-in LibreHardwareMonitor sensors, local interactive Three.js hardware model, PresentMon frame capture, histories, process analysis, native tray and noninjected desktop overlay. Includes self-contained compiled files and a per-user Inno Setup installer.

This prerelease is published only after automated tests, Windows Release build, installer generation and installation/launch/uninstallation smoke checks pass. Those checks do not qualify real gaming hardware. Intel/NVIDIA/AMD sensor accuracy, real game capture, multi-monitor/sleep-resume and prolonged stability remain untested. See documentation/KNOWN-LIMITATIONS.md and documentation/TESTING.md in the source or ZIP.

Unsigned release. Windows 11 x64 required. If WebView2 is absent, setup downloads it using Microsoft's official signed bootstrapper. No administrator requirement, driver installation, fan control or game injection. Sensor access is disabled by default; enable it in Settings when desired.
